# Sign-in brand assets

- `github-mark-white.svg`: unmodified official white Invertocat from
  [GitHub's logo bundle](https://brand.github.com/GitHub_Logos.zip).
- `google-mark.png`: unmodified full-colour gradient G from
  [Google Identity's official icon](https://developers.google.com/static/identity/images/g-logo.png).

The assets are imported explicitly by `OAuthButton`, shared by sign-in and
invitation sign-up. Marks keep their aspect ratio and are decorative beside the
provider's full text label. GitHub uses a dark button; Google uses a white button
with the official colour mark and locally hosted Google Sans Medium.

Google Sans is under SIL OFL 1.1; see `public/fonts/GoogleSans-OFL.txt`.

[GitHub](https://brand.github.com/foundations/logo),
[Google](https://developers.google.com/identity/branding-guidelines).
